# Alfheim Website v1.2

Static GitHub Pages website. Upload **all files and the assets folder** to the published Pages root (with `index.html` at root).

Pages: Home, Server, Rules, Getting Started, News, Disclaimer.

Join button: custom HTML in-page confirmation followed by in-page waiting message and `steam://` protocol handoff. Browsers may show an additional operating-system/browser permission prompt; a website cannot suppress it or verify successful connection.

No RCON credentials or server password are embedded. No live status panel.
